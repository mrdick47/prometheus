# library/

Kiwix ZIM archives live here (BAC-143). Git ignores `*.zim`.

Intended sources: English Wikipedia with images, WikiMed, Wiktionary,
Wikivoyage, Wikibooks, selected Stack Exchange ZIMs, iFixit, Project
Gutenberg, Appropedia, Khan Academy, and OpenStax / LibreTexts.

`kiwix-serve` is started against every `*.zim` in this directory (or
a future `library.xml` if one is added).
